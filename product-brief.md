# DeliveryLens AI

## Product Vision

DeliveryLens AI is a simple AI-powered assistant designed to help Project Managers and Delivery Managers turn unstructured project information into clear delivery insights.

## Problem

Project and Delivery Managers receive information from many sources, including project updates, meetings, RAID logs and stakeholder communications.

It can take significant time to turn this information into a concise view of:

- Current project status
- Key risks
- Issues
- Actions
- Escalations
- Executive updates

## Target User

Primary user:

Project Managers and Delivery Managers.

## Proposed Solution

The user will paste project information into DeliveryLens AI.

The AI will analyse the information and produce:

1. Overall RAG status
2. Executive summary
3. Top project risks
4. Key issues
5. Actions and owners
6. Items requiring escalation
7. Draft stakeholder update

## MVP Goal

Create a simple working application that allows a user to:

1. Paste project information
2. Click "Analyse Project"
3. Receive a structured AI-generated delivery assessment

## Out of Scope

The first version will NOT include:

- Jira integration
- Microsoft Teams integration
- User accounts
- Payments
- Mobile application
- Complex AI agents
- Project management functionality

## Success Criteria

The MVP will be considered successful if:

- A user can enter project information
- The AI can analyse the information
- The application produces useful delivery insights
- The application avoids inventing information that was not provided
- The application can be demonstrated to another person

## Project Approach

The product will be developed as a small MVP using an iterative approach.

Problem → Design → Build → Test → Improve → Launch
